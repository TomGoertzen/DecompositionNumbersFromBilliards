Lievis: Joel Gibson
------------------
The typography, palette, layout and interaction design follow Lievis:
https://www.jgibson.id.au/lievis/
https://github.com/joelgibson/lievis

The bundled KaTeX distribution and four body/UI font files were copied from
the local Lievis source tree. Their upstream authors and licences are listed
below. Lievis's TypeScript library and Svelte components are not bundled or
imported by the review website. This is not a claim that all visual styling
was designed independently of Lievis.

No explicit licence for Lievis-specific code was found in the local checkout
or the checked GitHub repository on 14 November 2026. Attribution alone is not
permission. Clarify permission for any adapted Lievis-specific source with
Joel Gibson before publication. See assets/vendor/lievis/SOURCE.txt.
